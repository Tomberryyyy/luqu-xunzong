# 数据与素材说明

## 数据范围

第六版运行数据为80条山东景点、14座城市，来自团队提供的《山东景点清单测试版2（80）》整理结果。原始表格和个人工作目录未随仓库上传。

`attractions.json`包括ID、名称、城市、标签、简介、推荐内容、注意事项、季节、图片URL、来源、表格标注核验日期和素材备注。`attributes.json`记录匹配属性、依据、known与soft等标记；资料缺失或仅有软性推断时不作为已确认符合条件。

## 已知核验边界

- 目前许多来源指向官网首页，仍需补齐支持具体事实的页面；不能据此宣称所有景点事实已全量核验。
- 表格中的核验日期是数据原有字段，不是访问仓库当天重新核验的证明。
- 现有体力等级均未完成核验，匹配时按未知处理；慢生活标签不能自动推出低体力或人少。
- SD004蓬莱阁、SD019养马岛、SD056云门山配图存在对应疑问，运行数据已留空，不展示疑似图片。

## 图片与授权

景点图片通过原有外部链接加载；仓库没有打包第三方景点照片。外部图片可能失效，页面会使用降级显示。

数据中的“视觉中国授权图库”等字段为团队表格原有说明，本仓库未提供可核验的许可凭证，也没有授予第三方图片的使用权。公开录屏、对外传播或商用前，应核实许可或换成自有／明确许可的素材。

首页截图只包含项目自身界面与山水装饰，不包含景点照片。当前多模态配套覆盖已有景点图片与AI辅助生成文字，不包含自动生成音频、视频或自动获取授权。

## 编辑建议

修改资料后同步核对对应属性。导入辅助脚本依赖规定的Excel字段；导入后运行 `node scripts/check_data.cjs`，再实际复核受影响的推荐。程序检查通过不等于事实与许可已核验。
