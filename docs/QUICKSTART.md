# 启动与模型配置

## 电脑本地运行

需要Python 3.8+。下载Release压缩包或源码，完整解压，Windows双击 `start_windows.bat`。

macOS / Linux在项目目录运行：

```sh
python3 server.py
```

浏览器访问 http://127.0.0.1:8006。Windows启动器会自动打开网页；请保留启动窗口。端口冲突时关闭此前启动的同版程序，或调整配置端口。

## 演示模式

默认 `LLM_MOCK=1`，返回本地示例，不调用真实模型。界面会标示演示模式；这可用于了解操作，不作为真实模型质量或真实测试的证明。

## 配置真实模型

Windows首次启动会从 `.env.example` 复制 `.env`。其他系统先手动复制：

```sh
cp .env.example .env
```

在本机 `.env` 内填写：

```dotenv
LLM_BASE_URL=https://your-provider.example.com/v1
LLM_API_KEY=填写你自己的密钥
LLM_MODEL=填写服务商提供的准确模型标识
LLM_MOCK=0
PORT=8006
```

示例域名不是可直接调用的服务地址。接口需要兼容 `/chat/completions`，请向服务提供方核对模型、访问权限与费用。保存后停止程序并重新启动。真实模式的请求会发往你配置的服务商。

密钥放后端本地配置，不填入网页，不上传GitHub，也不发截图。仓库只提供空白模板；`.gitignore`排除了私密配置。

## 完成一次探索

1. 用自然语言写偏好、兴趣和排除条件，按需选择城市。
2. 点击“发送，理解我的偏好”，检查六维画像与依据。
3. 修改或删除不准确内容，点击“确认偏好，开始匹配景点”。
4. 查看每张卡片的符合与未知条件；核查配图、季节与事实来源。
5. 编辑标题和文案，保存并审阅，复制或导出TXT／JSON。
6. 新探索或刷新前先导出。当前没有自动保存的历史会话。

如果使用“跳过画像，按关键词匹配”，不能据此认为程序已经理解整段自然语言中的否定或限制。

## 失败处理

画像失败时保留错误信息并核对配置；文案失败可在单张卡片重试。不要把失败结果当作生成成功。条件冲突时，修改画像后重新确认。

## 关于在线访问

GitHub仓库是源码与程序下载入口。GitHub Pages只提供静态网页，无法运行本项目的Python后端和保管模型密钥；目前没有发布可用的在线真实模型服务。不要把本地网址填成对外访问链接。
