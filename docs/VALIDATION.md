# 验证记录与适用边界

## 本地检查

`node scripts/check_data.cjs`提供15项不依赖真实模型的检查：数据数量、ID与城市、属性覆盖、登山排除、海边散步例外、建筑摄影组合兴趣、拍照误匹配、条件冲突、亲子及节奏证据、未知体力、城市过滤和存疑配图等。

开发过程中还完成模拟界面、冲突清理与恢复、文案编辑、复制／导出及多个屏幕宽度检查；这些结果不能替代真实接口稳定性测试。
